## About

THLMarkdown (TanghuluNote) is a professional Markdown authoring and typesetting suite designed for technical writers, researchers, and knowledge creators, harmonizing oriental aesthetic elegance with advanced cross-platform rendering technology.

Write source text on the left and read the rendered layout on the right, backed by deep support for KaTeX mathematical equations, Mermaid diagrams, and aesthetic knowledge cards.

## 🌟 Four Exclusive Distinctive Features

### 🪶 1. Moji Knowledge Cards (Oriental Aesthetic Card Generator)
- **One-Click Generation**: Turn highlighted quotes or paragraphs into breathtaking aesthetic knowledge cards with a single click.
- **Classic Aesthetic Themes**: Choose from exclusive themes: "Rice Paper & Ink", "Bamboo Green", "Midnight Gold", and "Dusk Violet".
- **Signature & Stamp**: Personalize with custom author signatures, vermilion seal stamps, dates, and QR codes; export in ultra-high lossless PNG.

![Exclusive Moji Knowledge Cards](images/screenshots/墨记卡片.png)

### 🧠 2. Thought-Stream Mind Board (Interactive Structure & Knowledge Map)
- **Dynamic Topology Board**: Automatically parses document headings (H1-H6) into an interactive dynamic mind board.
- **Node Folding & Filtering**: Features node folding, word-count heat sensing, and keyword filtering.
- **Bidirectional Navigation**: Canvas nodes and source text are linked in real time—click any node to jump directly to the corresponding paragraph.

![Thought-Stream Mind Board](images/screenshots/墨记拓扑看板.png)

### 📊 3. Multi-Dimensional Document Analyzer (In-Depth Telemetry)
- **Full-Spectrum Metrics**: Comprehensive statistics including character count, Chinese/English weighted reading time, code density, and paragraph pace.
- **Element Distribution**: Visual distribution of LaTeX formulas, Mermaid diagrams, tables, and asset links.
- **Health Telemetry**: Generates document structure health scores with actionable typesetting tips, plus one-click telemetry report copying.

![Multi-Dimensional Document Analyzer](images/screenshots/墨记分析.png)

### 🖨️ 4. Dual-Track Isolated High-Fidelity Export
- **No Style Pollution**: Completely eliminates dark-mode style pollution (no more black text on black background in exported PDFs).
- **Dual-Track Isolation**: Decouples viewing UI themes from publishing output standards.
- **High-Fidelity Multi-Format**: High-fidelity export to publication-grade PDF (A4/Letter), Word (.docx) with embedded formulas and diagrams, standalone HTML, and multi-page images.
- **Smart Pagination Algorithm**: Boundary-aware smart pagination algorithm prevents diagram and code block clipping across page splits.

![Dual-Track Isolated High-Fidelity Export](images/screenshots/墨记导文件.png)

## 📝 Dual-Pane Writing & Professional Extensions

### ⚡ Immersive Dual-Pane Workspace
- **Real-Time Split Preview**: Edit on the left and see accurate, instant rendering on the right. Easily switch to "Immersive Fullscreen", "Edit Only", or "Preview Only" modes.
- **Typewriter & Focus Modes**: Keep your active line perfectly centered and dim inactive paragraphs to eliminate distractions and maintain your flow state.
- **Sync Scroll**: The editor and preview panes scroll in perfect harmony, keeping you oriented even in massive documents.
- **Flawless CJK Optimization**: The underlying input engine is deeply optimized for native macOS Pinyin and other CJK input methods, completely resolving issues like dropped keystrokes or interrupted text composition.

![Editor mode — distraction-free typing](images/screenshots/markdown编辑.png)

### 📐 Academic & Engineering Formula & Diagram Support
- **KaTeX Vector Equations**: Native KaTeX vector mathematical formula rendering (inline `$` and display block `$$`).
- **Mermaid Diagrams**: Flicker-free off-screen rasterization of Mermaid flowcharts, sequence diagrams, class graphs, state diagrams, and Gantt charts.
- **Code Syntax Highlighting**: Robust syntax highlighting for mainstream programming languages.

![Rich rendering — LaTeX math and typography](images/screenshots/markdown渲染.png)

![Mermaid diagram support](images/screenshots/markdown流程图.png)

### 📚 Multi-Window & Document Outline
- **Native Multi-Window**: Open multiple, independent document windows simultaneously without cross-window interference.
- **File Tree & Document Outline**:
  - The left sidebar features a **File Tree** for lightning-fast navigation between notes in your current workspace.
  - The right sidebar auto-generates a clickable **Document Outline** based on your headers.
- **Live Status Bar**: Track cursor position (line/col), word count, character count, and total lines in real time.

![File tree and document outline](images/screenshots/markdown目录+大纲.png)

### 🖼️ Asset Management & Custom Preferences
- **Drag & Paste**: Drag images directly into the editor or simply paste screenshots from your clipboard using keyboard shortcuts.
- **Relative Path Auto-Save**: Automatically creates a local `assets` directory next to your Markdown file to store images.
- **PicGo Cloud Upload**: Built-in support for PicGo cloud storage services to automatically upload inserted images and receive Markdown web links.
- **One-Click Asset Cleaner**: Locate and delete orphaned images in your assets folder that are no longer referenced in your document.
