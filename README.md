## About

Tanghulu Notes is a Markdown editor for macOS built around a focused split workspace: write source on the left and read the rendered result on the right.

Whether you are drafting notes, technical documentation, study material, or articles, Tanghulu Notes keeps source text and final layout side by side.

## 🌟 Features

### 📝 Immersive Writing & WYSIWYG
- **Real-time Dual-pane Preview**: Edit on the left and see accurate, instant rendering on the right. Easily switch to "Immersive Fullscreen", "Edit Only", or "Preview Only" modes.
- **Typewriter & Focus Modes**: Keep your active line perfectly centered and dim inactive paragraphs to eliminate distractions and maintain your flow state.
- **Sync Scroll**: The editor and preview panes scroll in perfect harmony, keeping you oriented even in massive documents.
- **Flawless CJK Optimization**: The underlying input engine is deeply optimized for native macOS Pinyin and other CJK input methods, completely resolving issues like dropped keystrokes or interrupted text composition.

![Editor mode — distraction-free typing](images/screenshots/markdown编辑.png)

### 📊 Professional Typography & Rendering
- **Full Syntax Compatibility**: Natively supports all standard Markdown elements including tables, task lists (checkboxes), strikethroughs, blockquotes, and more.
- **Academic & Engineering Extensions**:
  - Built-in **LaTeX Math** rendering engine (KaTeX) for beautiful, complex mathematical formulas.
  - Native support for **Mermaid** flowcharts, sequence diagrams, and Gantt charts directly from code blocks.
  - Robust **Syntax Highlighting** for dozens of mainstream programming languages.

![Rich rendering — LaTeX math and typography](images/screenshots/markdown渲染.png)

### 📈 Mermaid Diagrams & Charts
- Render flowcharts, sequence diagrams, class diagrams, and state diagrams right inside your document.
- Easy to write and maintain diagrams with plain code blocks.

![Mermaid diagram support](images/screenshots/markdown流程图.png)

### 📚 Powerful Document & Window Management
- **Native Multi-window Support**: Open multiple, independent document windows simultaneously.
- **File Tree & Document Outline**:
  - The left sidebar features a **File Tree** for lightning-fast navigation between notes in your current directory.
  - The right sidebar auto-generates a clickable **Document Outline** based on your headers.
- **Live Status Bar**: Track cursor position (line/col), word count, character count, and total lines in real time.

![File tree and document outline](images/screenshots/markdown目录+大纲.png)

### 🖼️ Smart Image Management
- **Drag & Paste**: Drag images directly into the editor or simply paste screenshots from your clipboard using keyboard shortcuts.
- **Relative Path Auto-save**: Automatically creates a local `assets` directory next to your Markdown file to store images. Your images will never break when sharing the folder.
- **PicGo Integration**: Built-in support for PicGo cloud storage services. Automatically upload inserted images and receive Markdown web links instantly.
- **One-click Asset Cleaner**: A built-in scanner helps you locate and delete orphaned images in your assets folder that are no longer referenced in your document.

### 🎨 Limitless Personalization
- **Flexible Theme System**: Flawlessly adapts to macOS Light and Dark modes (with auto-sync to system settings).
- **Curated Code & Typography Themes**: Choose from an array of beautiful built-in Preview Themes and Code Highlight Themes.
- **Granular Control**: Customize editor font family, font size, Tab indent size, word wrap, line numbers, and active line highlighting.

### 🔄 Seamless Productivity
- **Rich Export Options**: Export as raw text, beautiful **HTML pages**, or high-quality **PDF files**.
- **Find & Replace**: Cmd+F quick keyword lookup and batch replacement with keyboard shortcuts.
- **Auto-save & Auto-refresh**: Set custom auto-save intervals and enable external file change detection so your data is always safe and up-to-date.
- **Reveal in Finder**: Instantly locate your active file on your disk with a single click.

## 🔒 Privacy First

Tanghulu Notes is a 100% local-first application.

- **Zero Account Requirements**: No sign-ups, no logins. Works right out of the box.
- **Zero Data Collection**: All your documents, notes, and images are stored exclusively on your local hard drive. Aside from lightweight local resource loading for chart rendering (like Mermaid), the app contains absolutely NO background trackers or ad SDKs. Your privacy is fully guaranteed.
